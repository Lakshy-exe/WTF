## 🎯 Project Objective

The objective of this project is to build a responsive, modern website for the Computer Engineering department at CHARUSAT. The page highlights academic programs, state-of-the-art laboratory facilities, research initiatives, and recent departmental news/achievements.

Key Features:
- **Semantic Markup:** Built using standard HTML5 tags (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS Layouts:** Utilizes Flexbox for header navigation & feature cards, and CSS Grid for the news section layout.
- **Responsive Design:** Includes media queries for smooth rendering across desktop, tablet, and mobile devices.
