# FoodExpress — Responsive Web Design (ITUS102 Practical 11)

A responsive online food ordering frontend built for **FoodExpress Pvt. Ltd.** using **Bootstrap 5** and **Tailwind CSS**, tested across multiple viewports and browsers.

## Project Structure
- `index.html`: Main landing page built using **Bootstrap 5** (Navbar, Grid System, Cards, Badges, and Contact Form).
- `menu.html`: Full menu catalog built using **Tailwind CSS** utility classes (`flex`, `grid`, responsive breakpoints).
- `css/custom.css`: Minimal custom hover transitions and smooth scrolling.
